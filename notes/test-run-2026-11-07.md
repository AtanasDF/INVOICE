# Full harness run, 2026-11-07 (cloud)

On `main` `23a6f9e`. Production build (`next start -p 3100`, checked: no `next dev`
process, 0 `next-devtools` in the page), `run-all.sh` with `JOBS=2`. No app code changed.

Container set-up, so nothing in the repo had to change: the harness hard-codes Mac paths,
so `/Applications/Google Chrome.app/.../Google Chrome` was made a wrapper for the
pre-installed Chromium with `--no-sandbox` (the container runs as root), and the four
`/System/Library/Fonts` files the clip generators use were linked to Liberation fonts.
zsh was installed, plus `npm install` in `harness/`. `worker/` needed `npm ci` too
(test-inbox-worker: `Cannot find package 'postal-mime'`); that was done after the first pass.
